    Google ships Gemini 4 Argon, with an unguarded edition for cyber defenders

    The model targets long, multistep work in code, finance, law, security and science.

    Google released Argon on 13 October after weeks of security testing and delays. It says internal teams using it produced more than 35% more AI-assisted code with nearly a third fewer rollbacks. Introductory API pricing is $2 per million input tokens and $10 per million output tokens, doubling after 30 November. Vetted defenders in its Fairwind Program get a version without the standard cyber guardrails, and in a separate DeepMind paper four Argon agents beat Minecraft's final boss in a single 27-hour run.

    This changes the picture because Frontier labs are now formally splitting capability by trust level: one model for the public, a less restricted one for vetted security partners. Expect that two-tier release to become the norm for models with serious hacking ability.
