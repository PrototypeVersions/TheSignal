DeepSeek gives away its serving engine, built for Nvidia and Huawei chips

A day after Washington ordered DeepSeek out of federal systems, the Chinese lab open-sourced DeepInfer, the software that runs its production service, with support for Huawei's Ascend 950 alongside Nvidia's Blackwell.

The Signal · Wednesday 21 October 2026

Key facts

  • DeepInfer was released on GitHub on 20 October under the Apache 2.0 licence.
  • It supports Nvidia Blackwell GPUs and Huawei Ascend 950 chips; older Nvidia chips are not listed.
  • It currently runs only DeepSeek-V4.1-Flash; DeepSeek says future models will be added to the same project.
  • DeepSeek says one cluster serves 155 trillion tokens a day; its published benchmarks are its own, run on Nvidia hardware.

What was released

DeepSeek published DeepInfer on GitHub on Tuesday 20 October under the permissive Apache 2.0 licence, describing it as the inference framework behind its large-scale production services, SiliconANGLE reports. A companion library prepares requests the same way as DeepSeek's official API. For now the engine runs only DeepSeek-V4.1-Flash, and the company says inference code for future models will go into the same project.

The software targets two kinds of hardware: Nvidia's Blackwell-generation GPUs and Huawei's Ascend 950 accelerators. Older Nvidia chips such as Hopper are not listed. Some features work only on Nvidia, and all of the published performance figures are DeepSeek's own, measured on Nvidia hardware.

How it works

Among the techniques described is a form of speculative decoding in which a small draft model proposes several tokens at once and a confidence filter discards weak guesses, which DeepSeek estimates raises throughput by 4–7%. The smallest efficient deployment it describes uses 64 GPUs for processing prompts and 64 for generating output. DeepSeek withheld some cache-management and load-balancing code as too tied to its own infrastructure. It says a single cluster serves 155 trillion tokens a day.

Background

In April 2025 DeepSeek declined to release its full engine. Since then it has worked more closely with Huawei, porting the TileLang kernel language to Huawei chips in September, and AI Weekly reports it has said it plans to pre-train on Huawei hardware by the end of the year. The release came a day after a US Department of Homeland Security order, made public on 19 October, barred DeepSeek products and tools built on them from federal civilian systems.

Why it matters

Giving away a production-grade serving stack that treats Huawei chips as a first-class target makes Chinese hardware a more practical choice for running Chinese models, just as Washington moves to shut those models out. It is a software release, not a new capability.
